Excel Real-World Sales Analytics

Project Overview

This project analyzes sales data using Microsoft Excel to identify business trends and generate actionable insights.

Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- PivotTables and PivotCharts
- Dashboard Visualization

Project Objectives

- Analyze sales performance.
- Identify top-selling products.
- Understand revenue and profit trends.
- Compare sales across categories and regions.
- Present insights through an Excel dashboard.
